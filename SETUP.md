# GitHub profile setup

This package is made for the public GitHub profile repository:
https://github.com/Kushi-14/Kushi-14

1. Download and extract the ZIP.
2. Open your profile repository on GitHub.
3. Upload `README.md` and the whole `assets/` folder, keeping the same folder names and paths.
4. Commit the changes, then open https://github.com/Kushi-14 to check the result.

## Included files

- `README.md`: Your GitHub profile layout and content.
- `assets/banner.svg`: Dark, monochrome profile header.
- `assets/badges/*.svg`: Three minimal, local text-only contact buttons.
- `assets/Kushi_NC_Resume.pdf`: Resume referenced by the contact button.

The GitHub Insights section uses a third-party service to keep the graphs current. Everything else in the design is stored locally inside this package.

**Privacy reminder:** The supplied resume includes contact details. Uploading it to a public repository makes the PDF publicly accessible. If you prefer not to publish the resume, omit that file and remove the Resume links from `README.md`.

No changes have been made to your online repository.
